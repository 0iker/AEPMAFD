# AEPMAFD - Sitio Web Oficial

Sitio web corporativo de la **Asociación Española de Psicopedagogía de la Motricidad, la Actividad Física y el Deporte (AEPMAFD)**.

Proyecto desarrollado con enfoque profesional, orientado a presencia institucional, posicionamiento SEO y escalabilidad.

---

## 🌐 Descripción

Este proyecto consiste en el desarrollo completo de la web oficial de la asociación, con el objetivo de:

- Presentar la organización de forma clara y profesional
- Difundir sus objetivos, actividades y estructura
- Mejorar su visibilidad online mediante SEO
- Ofrecer una experiencia moderna, rápida y responsive

---

## 🚀 Tecnologías utilizadas

- **Astro** – framework moderno para sitios estáticos
- **Tailwind CSS** – sistema de estilos utility-first
- **JavaScript** – interactividad (menú responsive, carrusel)
- **pnpm** – gestión de dependencias

---

## ⚙️ Funcionalidades principales

- Diseño completamente **responsive**
- Navegación optimizada con **transiciones (Astro View Transitions)**
- Sistema de componentes reutilizables:
  - Header
  - Footer
  - Content layout
  - PageHero
  - Carrusel

- SEO completo:
  - Meta tags dinámicos
  - Open Graph
  - Twitter Cards
  - Canonical URLs
  - JSON-LD (Organization)
  - Sitemap automático
  - robots.txt

- Optimización de rendimiento (Astro + assets)

## 🛠️ Instalación y uso

```bash
# instalar dependencias
pnpm install

# desarrollo
pnpm dev

# build producción
pnpm build

# preview
pnpm preview
```
