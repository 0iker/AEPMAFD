# AEPMAFD - Sitio Web Oficial

Sitio web oficial de la **Asociación Española de Psicopedagogía de la Motricidad, la Actividad Física y el Deporte**.

![Logo AEPMAFD](./assets/logo/AEPMAFD_logo(sin%20fondo).png)

## 📋 Descripción

La AEPMAFD es una organización española concebida para promover, formar, acreditar y difundir el conocimiento en Psicopedagogía de la Motricidad, la Actividad Física y el Deporte a todos los interesados.

Este repositorio contiene el código fuente del sitio web institucional que presenta:

- **Información institucional** sobre la asociación
- **Objetivos y misión** de la organización
- **Actividades y servicios** que ofrece
- **Estructura organizativa** y equipo directivo

## 🌐 Sitio Web

El sitio web está disponible en: [www.aepmafd.es](https://www.aepmafd.es)

## 🚀 Características

- **Diseño Responsive**: Adaptable a dispositivos móviles y escritorio
- **Navegación Intuitiva**: Menú hamburguesa en móviles, horizontal en escritorio
- **Carrusel de Imágenes**: Presentación visual automática en la página principal
- **SEO Optimizado**: Metadatos y estructura apropiada para motores de búsqueda
- **Accesibilidad**: Implementación de buenas prácticas de accesibilidad web

## 🔧 Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/0iker/AEPMAFD.git
   ```

2. **Navegar al directorio:**
   ```bash
   cd AEPMAFD
   ```

3. **Abrir en navegador:**
   Simplemente abre `index.html` en tu navegador web preferido.

   O si prefieres usar un servidor local:
   ```bash
   # Con Python 3
   python -m http.server 8000
   
   # Con Node.js (si tienes http-server instalado)
   npx http-server
   ```

4. **Acceder al sitio:**
   Visita `http://localhost:8000` en tu navegador.
